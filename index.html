講義文字起こしノート

⚠️ 利用にあたっての注意事項
  • このアプリは付属のサーバー経由でOpenAIのWhisper APIを利用します。ターミナルで npm start を実行し、表示された http://localhost:3000 を開いてください（初回のみ npm install が必要）。
  • 対応ブラウザは Google Chrome 推奨です（最新版を使ってください）。
  • 「開始」で録音、「停止」を押すと録音全体をまとめて文字起こしします。録音が長いほど処理に時間がかかります。
  • 1回の録音は約25MB（ビットレート抑制で目安2時間前後）まで。長い講義は途中で一度停止して区切ると安全です。
  • ページを更新（リロード）すると、文字起こし内容はすべて消えます。更新前に「保存」または「校正依頼」ボタンでテキストを書き出してください。
  • マイクの使用を許可してください。話者に近いマイクほど精度が上がります。
  • API利用料が発生します（目安: 録音1分あたり約1円）。
