# 講義文字起こしノート

大学の講義を録音し、OpenAI の Whisper API で高精度に文字起こしする Web アプリです。
文字起こししたテキストはコピー・`.txt`保存・ChatGPT / Gemini への校正依頼ができます。

## 主な機能

- 🎙️ マイクで録音 → 停止すると録音全体をまとめて文字起こし
- 📋 テキストをクリップボードにコピー
- 💾 `.txt` ファイルとして保存（ファイル名に日時を自動付与）
- 🤖 ChatGPT / Gemini への校正依頼（指示文を自動付与）
- 🌙 ダークモード対応・スマートフォン対応

## 仕組み

ブラウザから直接 API を呼ぶとキーが漏れるため、付属の Node.js サーバー（`server.js`）が
中継し、API キーはサーバー側の `.env` にのみ保存します（ブラウザには渡りません）。

```
ブラウザ（録音） → ローカルサーバー(/transcribe) → OpenAI Whisper API
```

## 必要なもの

- [Node.js](https://nodejs.org)（LTS版）
- [OpenAI の API キー](https://platform.openai.com/api-keys)（※利用には残高のチャージが必要）

## セットアップ

```bash
# 1. 依存パッケージをインストール（初回のみ）
npm install

# 2. APIキーを設定（.env.example をコピーして .env を作成）
#    .env を開き、OPENAI_API_KEY=sk-... を自分のキーに書き換えて保存
cp .env.example .env

# 3. サーバーを起動
npm start
```

起動後、ブラウザで **http://localhost:3000** を開いてください。

> Windows (PowerShell) の場合、手順2のコピーは `Copy-Item .env.example .env` を使ってください。

## 使い方

1. 「▶ 開始」で録音を開始（マイクの使用を許可）
2. 「■ 停止」で録音を終了 → 自動で文字起こしが始まる
3. 結果を「コピー」「保存」、または「校正依頼」で AI に整えてもらう

## 注意事項

- **API 利用料が発生します**（whisper-1：約 $0.006/分。90分の講義で約80円）。
- 1回の録音は **約25MB（目安2時間前後）** まで。長い講義は途中で一度停止して区切ってください。
- ページを更新（リロード）すると文字起こし内容は消えます。事前に保存してください。
- 話者に近いマイクほど精度が上がります。
- `.env`（API キー）は絶対に公開リポジトリへコミットしないでください（`.gitignore` で除外済み）。
